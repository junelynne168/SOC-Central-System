# Automation Rules

- Do not begin coding production automations during the architecture phase.
- Automate only an approved, documented workflow.
- Keep test and live operation clearly separated.
- Use authoritative prospect and customer records.
- Prevent duplicate actions and duplicate records.
- Preserve human approval for sensitive communication.
- Record inputs, outputs, timestamps, status, and errors.
- Stop safely when required data, approval, or integration access is missing.
- Verify outcomes independently where possible; provider acceptance alone is not delivery.
