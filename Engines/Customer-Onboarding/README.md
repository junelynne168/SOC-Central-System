# Customer Onboarding Engine

## Purpose

Help an engaged prospect create and send a first free card, then move toward sign-up or appropriate personal support.

## Inputs

- Engaged prospect record
- First-free-card access
- Approved iPhone demonstration
- Optional approved computer tutorial

## Outputs

- Free-card outcome
- Qualified-lead decision evidence
- Sign-up or appointment outcome

## Boundary

The 3-minute iPhone demonstration is primary. The 7-minute computer tutorial is optional. The final step is sign-up or an appointment.
