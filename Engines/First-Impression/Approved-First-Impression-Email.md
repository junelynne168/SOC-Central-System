Status: Active design source for the Bobbi test email

## Design Authority

Use the attached reference image recreated in:

- `First-Contact-Email-Design-Reference-V2.png`

The rebuilt email must match the reference structure closely:

- wide desktop layout
- hero collage across the top
- serif headline
- three benefit columns in one row
- bottom explanation bar
- white background
- black main text
- warm gold/brown accent
- no email-client mockup
- no blue CTA button
