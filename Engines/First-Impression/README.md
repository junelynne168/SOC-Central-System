# First Impression Engine

## Purpose

Create a relevant, personalized first impression using approved messaging and assets.

## Inputs

- Reviewed prospect record
- Approved First Impression Email specification
- Approved 30-second SOC introduction

## Outputs

- Human-approved first contact
- Send and delivery evidence when available
- Engagement signals for the Customer Journey Engine

## Boundary

No external communication may be sent without the required human approval and destination checks.
