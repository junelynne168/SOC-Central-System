# Experience-Driven Design

## Purpose

The SOC system is designed around customer experiences rather than individual pages, emails, or software components.

Every future feature begins by defining the customer experience before any screen, HTML, automation, or implementation is created.

## Core Design Question

> "What experience are we creating?"

NOT

> "What page are we building?"

## Every Experience Must Define

1. Customer Emotion
2. Customer Question
3. Customer Action

Only after those are approved may Atlas and Codex design:

- Pages
- Emails
- Graphics
- HTML
- CSS
- Automation
- Code

## Design Rule

Every screen must answer ONE customer question.

Every scroll must create ONE emotional step.

Never design technology before the experience.
